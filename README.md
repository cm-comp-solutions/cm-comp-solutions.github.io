# Clayton Meireles

Apresentação profissional: experiência empresarial, contabilidade, tributação, desenvolvimento e inteligência de negócios.

Site: [https://cm-comp-solutions.github.io/](https://cm-comp-solutions.github.io/)

## Estrutura

- `index.html`: apresentação e conteúdo.
- `style.css`: identidade visual e layout responsivo.
- `script.js`: entradas ao rolar e ano do rodapé.
- `assets/`: foto, logo aprovada e ícone.

Site estático, sem dependências de compilação. As fontes são carregadas do Google Fonts, com alternativas locais.

## Publicação

GitHub Pages a partir de `main`, pasta raiz. Alterações nessa branch atualizam a publicação.
